# Learn the Kuiper: version 3 (5 Oct 2026, 00:10 London)

Every dot has an address. Learn the rule. Help electrify the world.

Open `index.html` and pick a way to play:
- ZOOM: fly from the whole Kuiper down to one star and the commit behind it.
- REAL KUIPER GAME: missions on the real wafer (first line, newest work, longest silence).
- RADAR: sweep the Kuiper like a radar scope; find any key or grid name by bearing and range.
- DRAW THE GRID: the stars fly out to draw every UK substation and the grid, then return to their own places.
- SOLAR STRINGS: grow a generic solar farm where every part has a permanent key.
- THE SHEET: one particle, then millions; change how many and how far it turns.
- DEEP: the maths and the proofs.

It runs offline: download `learn-the-kuiper.zip`, unzip, open `index.html`.

The placement rule is the live Kuiper's own code (`kuiper-law.js`), checked against it with 0 differences in 11,000,008 keys.
Map data: (c) OpenStreetMap contributors, ODbL; coastline: Natural Earth, public domain.
Illustrative only: a pre-sales and learning tool, not a design study.
