# Learn the Kuiper: version 4 (published 4 Oct 2026, 23:46 London, read from the clock)

Every dot has an address. Learn the rule. Help electrify the world.

Open `index.html` and pick a way to play. New in this version:
- Stars everywhere, and a joystick on touch screens: fly across the Kuiper (ZOOM).
- RADAR fills the screen, with its controls in one MENU sheet.
- Fixes from two independent reviews (Codex and an independent checker): timer leaks, an angle that went wrong at huge
  counts in practice mode, and several statements in DEEP corrected.
- THE SHEET now draws every dot at small counts (the previous public version dropped some).
- A NOTICE file with sources and licences.

Runs offline: download `learn-the-kuiper.zip`, unzip, open `index.html`.

The placement rule is the live Kuiper's own code (`kuiper-law.js`), checked against it with 0 differences in 11,000,008 keys.

Correction: the previous public folder `../202610050010/` was actually published at about 23:20 on 4 Oct 2026. Its folder
name and the time in its README were a labelling error by the builder (an estimated time, not a clock reading). It is kept
unchanged so links do not break.

Earlier versions are kept beside this folder and never overwritten.
